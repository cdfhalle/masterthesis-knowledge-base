# Masterthesis Knowledge Base

Obsidian-friendly markdown vault for research notes, sources, and findings.

## How it works

Drop a resource or finding in chat with **Masterthesis Knowledge Base**. New material is filed here under a consistent structure.

## Structure

- `sources/` — papers, links, and primary materials (one note per source)
- `notes/` — working notes and literature digests
- `topics/` — topic overviews and maps
- `findings/` — claims, results, and takeaways worth keeping

See `INDEX.md` for the current map of the vault.
