# Code quality metrics for AI-generated code

## Idea

Research new code quality metrics aimed specifically at AI-generated code—beyond classic maintainability scores—to capture how agents shape architecture, accumulate slop, and preserve (or erode) intentional design over iterative edits.

## Exploration

Ask whether metrics can measure architectural coherence, rationale retention, and long-horizon degradation rather than only local correctness. Connect to [[architectural-reasoning-for-coding-agents]] and [[slopcodebench-coding-agents-degrade-long-horizon]].
