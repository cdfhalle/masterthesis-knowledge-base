# AST-Grep

- AST-aware, polyglot tooling for structural code search, linting, rewriting, and code outlines; patterns match syntax rather than plain text.
- Possible agent-tooling angle: give coding agents structure-aware search, inspection, rule testing, and codemod primitives. Relevance to this thesis is **exploratory / not yet established**.
- Official docs list CLI modes such as `run`, `outline`, `scan`, `test`, and `lsp`; the project supports 20+ languages via Tree-sitter.
